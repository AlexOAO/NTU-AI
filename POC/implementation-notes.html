台語 AI 語音防詐 POC — 實作備忘錄

最後更新：2026-05-27

1. 快速啟動

# 安裝依賴（需安裝 uv）
uv sync

# 設定環境變數
cp .env.example .env
# 編輯 .env，填入 ANTHROPIC_API_KEY

# 啟動
uv run python app.py
# 開啟 http://localhost:7860

4. 環境變數說明

變數必填說明
ANTHROPIC_API_KEY✅ 必填Claude API 金鑰
HF_API_TOKEN選用HuggingFace 推論 API 金鑰。未設定時停用 ASR，僅文字輸入
HF_MODEL_ID選用ASR 模型 ID，預設 openai/whisper-large-v3-turbo
⚠️ 台語 Tv0.5 模型
台南大學 × 國科會的 Whisper-Taiwanese Tv0.5 模型 ID 需另行確認。 請至 HuggingFace Hub 搜尋 whisper-taiwanese 或 Tv0.5， 取得正確 model ID 後填入 HF_MODEL_ID。

5. FSM 狀態機

intro → s1_trust → s2_problem → s3_solution → s4_pressure → s5_action
                                                                    ↓
                                                              exit_win (識詐)
                                                              exit_lose (受騙)

任何狀態偵測到識詐語句（escapeDetected=true）立即跳 exit_win。 s5_action 配合超過 2 回合 → Claude 回傳 exit_lose。

7. 測試流程

  1. 選擇「醫療神藥詐騙」→ 按「開始模擬」→ 確認 AI 開場白顯示 + 語音播放
  2. 文字輸入「我要掛電話」→ 確認 exit_win 觸發 + 報告頁顯示
  3. 重新開始 → 連續回應配合詐騙者 5+ 回合 → 確認 exit_lose 觸發
  4. 若有 HF token → 錄音測試 ASR 流程
